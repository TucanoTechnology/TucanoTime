# Dependencies

- Confirm the latest stable version using the ecosystem's own tooling before adding or upgrading
  a dependency. The repository's `AGENTS.md` records the command for its toolchain.
- Prefer well-maintained, stable releases over bleeding-edge versions.
- Prefer an existing dependency or a platform feature to a new one.
- Removing or downgrading a dependency needs a ticket.
